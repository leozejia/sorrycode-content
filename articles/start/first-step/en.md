# First Time Using SorryCode

SorryCode provides model APIs for agent tools such as Codex, Claude Code, and WorkBuddy. Start by choosing a tool, then follow its guide to install and connect it.

<h2 id="choose-tool">Choose an Agent Tool</h2>

| Tool | Good for | Setup guide |
| --- | --- | --- |
| **Codex** | The default choice for code, files, and local tasks, with a visual app | [Codex](/docs/runtime/codex) |
| **Claude Code** | Code and terminal tasks with Claude models | [Claude Code](/docs/runtime/claude-code) |
| **WorkBuddy** | Documents, spreadsheets, and local files in a desktop app | [WorkBuddy](/docs/runtime/workbuddy) |
| **Grok CLI** | Grok models and xAI capabilities | [Grok CLI](/docs/runtime/grok-cli) |
| **Kimi Code** | Coding and long-context tasks with Kimi models | [Kimi Code](/docs/runtime/kimi-code) |

If you are unsure, start with Codex.

<h2 id="prepare-key">Create an API Key for the Right Group</h2>

Sign in to the [SorryCode console](https://sorrycode.com), confirm that your balance is available, and create an API key for the tool you selected. Use separate keys for different tool groups; they still draw from the same account balance.

See [Create API Key](/docs/start/create-api-key) for the steps and group rules. Do not reuse one key across tools that require different groups.

<h2 id="continue">Continue with the Tool Guide</h2>

Each tool page contains its current installation method, configuration entry, and first verification task. If the tool is already installed, use the same page and complete only the SorryCode connection steps.

For a manual API check, see [First Request](/docs/start/first-request). For shared errors, see [Common Errors](/docs/troubleshoot/common-errors).
