# Codex

If you are unsure which agent to choose, start with Codex. It can read files, edit projects, and run local tasks.

## 1. Install the desktop app

Follow the [official Codex installation guide](https://learn.chatgpt.com/docs/app) to download the desktop app. The current website calls it the ChatGPT desktop app; choose Codex inside the app after installation.

## 2. Enable it in Magpie

Complete [Configure SorryCode in Magpie](/docs/agents/magpie). In the Agent panel, find Codex, turn on **Connect**, and choose a model. Fully quit the desktop app after setup, then reopen it.

You do not need to run a separate SorryCode setup script or edit configuration files.

## 3. Open a folder and try a task

Open the folder you want to work with in Codex and send:

```text
Look through this folder and tell me which files I should read first. Do not modify or delete any files.
```

Confirm that it reads the right folder and replies before starting real work. For images, documents, and other tasks, see [Skills](/docs/skills/featured-skills). For connection errors, see [Common Questions](/docs/start/common-errors).
