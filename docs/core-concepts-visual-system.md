# 核心概念章节视觉系统

更新时间：2026-08-06

这份文档定义 `articles/concepts/` 的视觉规则，供内容和素材维护者使用。所有公开图片同时遵守 `docs/public-article-assets.md`。

## 目标

核心概念章节面向第一次接触 AI、Agent、Prompt 和 Context 的读者。封面负责建立方向感，正文插图负责解释流程和局部关系。

- 整组教程保持统一识别度
- 每张封面只表达一个核心概念
- 图片辅助理解，不代替正文结论

## 主风格

封面和正文解释图统一使用：

```text
Open Visual Grammar: whiteboard-operator-sketch
```

它以白板手绘和低科技物理动作为主，把抽象概念转成容易辨认的操作关系。系列内统一使用 GanFan 线团小工、细黑手绘线条和少量红、橙、蓝标注。

封面和正文图承担不同任务：

- 封面图保持疏朗，只放一个动作和少量标签
- 正文图可以承载步骤、对比和局部解释
- 流程图、架构图和信息密集页面不作为封面

## 封面约束

| 项目 | 要求 |
| --- | --- |
| 文件名 | `cover.png` |
| 位置 | `articles/concepts/<slug>/cover.png` |
| 生成尺寸 | `1536x1024` |
| 显示安全区 | 中间 `1536x768` |

生成时显式传入 `--size 1536x1024`，重要主体完整留在安全区内。不要用默认方图，也不要依靠后期裁切修正比例。

封面应包含：

- 纯白或近白背景
- 一个 GanFan 线团小工
- 一个低科技物件或路径
- 一个能解释概念的物理动作
- 至少 35% 留白

封面不要使用深色商业海报、巨型标题、随机英文杂志元素、复杂 UI、正式架构图或多概念信息图。小工保持克制，不做成表情夸张的贴纸或吉祥物。

## 图片文字

文章标题由页面呈现，不交给图片生成器绘制。

封面可以出现 2 到 6 个短中文标签，每个标签不超过 1 到 3 个词。标签不能承担文章结论，即使生成失败，画面也应成立。提交前逐字检查所有图片文字。

## 评审

提交前确认：

- 主隐喻一眼可以辨认
- 主角、线条、颜色和信息密度与系列一致
- 没有乱码、条码、期刊编号或随机 logo
- 图片原生生成于规定尺寸，主体位于安全区
- 图片符合公开资源的格式、大小和隐私要求

## 生成与存储

候选图先放媒体临时区。方向确认后，只把最终图放入对应文章目录，不提交请求日志、失败候选或生产 prompt。需要保留的生成方法写进内部视觉规范，不写进公开文章。
